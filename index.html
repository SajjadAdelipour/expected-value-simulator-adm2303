One result can be 1, 2, 3, or 4. Over many independent repetitions under the same conditions, the average of the observed values tends to approach E(X) = 3.

03 · Interpret the pattern

What should students notice?

1

One result is unpredictable

The expected value does not tell us what the next observed value will be.

2

Early averages fluctuate

Each new result has a large effect when only a few values have been observed.

3

The average stabilizes

With many independent repetitions, the running average tends to move closer to E(X) = 3.

Expected value of this distribution E(X) = ΣxP(x) = 1(0.1) + 2(0.2) + 3(0.3) + 4(0.4) = 3

Important: E(X) describes a long-run average, not the outcome of one repetition. Here, 3 happens to be a possible value; for some distributions, the expected value is not one of the possible values.
